# Breakout Clean

La versión más ligera de Breakout. Fondo blanco puro con azul y grises como únicos protagonistas. Para documentos formales, reportes y materiales que deben verse profesionales sin perder la identidad.

## Color Palette

- **Blanco**: `#FFFFFF` - Fondo principal
- **Azul Breakout**: `#2430FF` - Títulos principales y elementos de énfasis
- **Gris oscuro**: `#1A1A1A` - Texto de cuerpo (nunca negro puro)
- **Gris frío**: `#E1E1E1` - Divisores, fondos de tarjetas, elementos secundarios

## Typography

- **Headers**: Poppins SemiBold
- **Body Text**: Raleway

## Best Used For

Documentos formales, reportes para sponsors, propuestas de alianza, materiales académicos, cualquier contexto donde se necesite claridad máxima con identidad Breakout.
