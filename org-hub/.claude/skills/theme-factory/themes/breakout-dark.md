# Breakout Dark

Versión premium y nocturna de Breakout. Fondo negro profundo con el azul como acento brillante. Para Young Ecosystem, eventos nocturnos y contenido que quiere sentirse exclusivo.

## Color Palette

- **Negro profundo**: `#0A0A0A` - Fondo principal
- **Azul Breakout**: `#2430FF` - Acento principal, títulos resaltados y CTAs
- **Blanco**: `#FFFFFF` - Texto principal
- **Gris cálido oscuro**: `#2A2420` - Fondos alternativos y tarjetas

## Typography

- **Headers**: Poppins Bold
- **Body Text**: Raleway

## Best Used For

Eventos nocturnos (Young Ecosystem), decks de pitch, presentaciones premium, contenido exclusivo, keynotes de apertura.
