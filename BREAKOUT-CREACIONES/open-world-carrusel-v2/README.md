# Open World — carrusel v2

Cada lámina usa una composición distinta generada con la herramienta built-in ImageGen. Las capas SVG solo añaden texto exacto y no cubren ni reconstruyen el arte.

No se incluyeron fecha, día ni horario porque `BREAKOUT-CONTEXTO/` contiene datos contradictorios. Deben confirmarse antes de producir una versión final con información del evento.

- `01-portada.png`: portada.
- `02-promesas.png`: oportunidades, prototipado y mentoría.
- `03-cierre.png`: cierre sin metadatos dudosos.
- `assets/`: composiciones raster originales de ImageGen.
