# Carruseles de Breakout

## Secuencia

Cada lámina tiene una sola tarea narrativa:

1. **Portada:** hook corto y una imagen o gesto visual dominante.
2. **Contexto:** por qué importa o qué problema abre.
3. **Desarrollo:** una idea, dato, persona o paso por lámina.
4. **Prueba o detalle:** agenda, perfiles, cifras, beneficios o ejemplo cuando corresponda.
5. **Cierre:** acción concreta, fecha/lugar o invitación a compartir/guardar/registrarse.

El número de láminas nace del contenido; no rellenes para alcanzar una cantidad arbitraria.

## Continuidad visual

- Mantén la misma retícula, márgenes, paleta y familia tipográfica.
- Repite un motivo que evolucione: una línea que atraviesa páginas, numeración, coordenadas, un círculo sketch o una trama wireframe.
- Alterna densidad. Una lámina cargada debe ir seguida de otra con más aire cuando el relato lo permita.
- Conserva fija una zona discreta para numeración o firma Breakout.
- El swipe debe sentirse como avance: usa dirección, recorte o continuidad de formas entre bordes sin depender de que Instagram muestre dos láminas simultáneamente.
- Genera una composición distinta con `imagegen` para cada lámina. Conserva el ADN visual usando referencias entre generaciones, pero cambia sujeto, encuadre, escala o densidad según la tarea narrativa.
- No simules variedad reutilizando la misma imagen con otro recorte, opacidad, tinte o panel encima.

## Texto

- Portada: una idea, no un resumen.
- Interior: frases cortas, listas pequeñas o un dato principal.
- Evita párrafos. Si el texto no cabe con lectura móvil cómoda, divide el contenido o pásalo al caption.
- Comprueba manualmente nombres propios, tildes, fechas, horas y lugares contra `BREAKOUT-CONTEXTO/`.

## Entrega

- Exporta todas las láminas con idénticas dimensiones y perfil de color.
- Abre la serie completa y también cada lámina individual.
- Verifica continuidad, orden de archivos, márgenes, contraste y que la portada funcione como miniatura.
- Revisa la serie en mosaico: debe leerse como una familia y no como la misma plantilla repetida.
